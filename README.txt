CHEF CHRISTINA WEBSITE

Files:
- index.html: website content and structure
- styles.css: responsive layout and visual styling
- script.js: mobile navigation and current footer year
- assets/: the four supplied photographs

PREVIEW LOCALLY:
Open index.html in a browser. An internet connection is required for the Google Fonts; the site otherwise works as a static website.

PUBLISH WITH GITHUB PAGES:
1. Create a new GitHub repository.
2. Upload the contents of this folder (not the outer folder itself).
3. Ensure index.html is in the repository root.
4. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish the site.
